# Memory Game

Простая и увлекательная игра на тренировку памяти, построенная на JavaScript.
Цель игры — найти все совпадающие пары карт с изображением версий неуязвимого за
минимальное количество ходов.

## Особенности

* **Простая механика:** Нажимайте на карточки, чтобы открыть их, и находите
  одинаковые пары.
* **Подсчет ходов:** Отслеживайте свой результат в процессе игры.

### Инструкция:

1. Установите [Node.js]([Node.js](https://nodejs.org/))
2. Сделайте форк этого репозитория: https://github.com/PogosStuido/memory-game
3. **Клонируйте форкнутый репозиторий на свой компьютер:**
   `git clone <https://github.com/<%your_github_username%>/memory-game.git>`
4. Перейдите в папку: `cd memory-game`
5. Перейдите в ветку разработки: `git checkout memory-game`
6. Установите зависимости проекта: `npm install`
7. Запустите локальный сервер: `npm run dev`
